*Applies at:* `function userIdentityBindingUnchanged() {`

    // createUserDocOnAuthCreate (functions/index.js, Admin SDK — bypasses every

    // decoration: the attacker never creates a privileged doc, they CONVERT one.

    // branch below except the President's own. No client code path anywhere in
    // the repo updates either field — the ONE writer of pendingPasswordSetup is
    // signupApprove's batch.set() at CREATE time (js/svc-approvals.js), and
