## 2. THE ONE THING BLOCKING THE OWNER

**The Office Team (monthly) payroll cannot pay anyone.**

`disbursePayRun` refuses while `STATUTORY[year].verified !== true`
(`js/departments.js` ~2144). The 2026 SSS / PhilHealth / Pag-IBIG / withholding
figures shipped as **placeholders** (`js/statutory-tables.js`).

This is **correct behaviour**, not a bug — paying real wages on invented
government rates, and remitting the wrong amounts, is worse than paying late.

**What unblocks it:** the owner (or whoever files his BIR returns) enters the
real 2026 rates at **Finance → Taxes & BIR → Gov Rates**, names the source, and
confirms. That writes `statutory_tables/{year}` and
`window.loadStatutoryTables()` merges it over the placeholder at sign-in. No
deploy needed. Built 2026-08-10 precisely because the flag previously lived in a
source file and nothing could write it.

> ⚠ **DO NOT INVENT THESE RATES.** Not from memory, not from a web search, not
> "they're probably still 5%". They decide what real people are paid and what is
> remitted to the Philippine government. If asked to fill them in, decline and
> explain why. The attestation exists for exactly this reason.

**Operations Team (weekly) CAN be paid** — its gate only bites on weeks that
actually deduct statutory.

## 6. HAZARDS THAT HAVE ALREADY COST MONEY OR WORK HERE

- **`git stash` / `reset --hard` / `checkout --` / `clean` — NEVER.** Multiple
  sessions edit this tree live. To verify in isolation, copy to a scratch dir.
- **The pre-commit hook re-stages `index.html`, `js/config.js`, `sw.js`.** It
  swept another agent's wiring into an unrelated commit today, leaving master
  referencing two scripts that did not exist (live 404). **Always
  `git diff --cached` before committing**, and stage explicitly — never `git add -A`
  (other sessions leave scratch files in the tree).
- **`git push` does NOT ship rules.** `firebase deploy --only firestore:rules`
  and `--only storage` are separate. CLI is at `~/.npm-global/bin/firebase`.
  **Deploy rules BEFORE the code that needs them**, or writes fail silently.
- **Rules: a missing field read THROWS and therefore DENIES.** Use
  `.get(field, default)`. Rules do NOT cascade into subcollections. A LIST query
  must be provable from the query alone — fencing `allow read` on a field broke
  every chat inbox today and was caught only in review.
- **A denied read renders as an empty list app-wide.** On a pay screen that is
  indistinguishable from "nobody is owed anything". Always distinguish
  "not found" from "could not read".
- **`openPage` keeps a dying panel ~300ms.** Scope every DOM lookup to its panel.
  811 sites were fixed for this; do not add more.
- **`closeModal()` is `history.back()` and is ASYNC.** Never
  closeModal()-then-open — use `openPage(..., {replace:true})`.
- **Backticks inside a template literal terminate it.** Broke a file and a
  workflow script today.
- **Live site 301s to `ravenmails.com`** — use `curl -sL` to verify a deploy or
  it reads as broken.
- **Manila helpers only** (`bizDate`/`bizHour`/`bizDow`). A raw `toISOString()`
  is UTC and has corrupted attendance and payroll here.
- **`js/money-core.js` is FROZEN**, 315 pinned tests. Additive only. Moving a
  money pin needs a stated ruling — that is the only legitimate reason.

## 7. HOW THIS SESSION WORKED, IF CONTINUING THE SAME WAY

Large tasks ran as `Workflow` fan-outs partitioned **strictly by file** (no two
agents ever own the same file), each build agent followed by an **adversarial
verifier** doing its own independent sweep. That caught, before anything shipped:
a chat fix that would have broken every inbox; a double-post guard that was dead
because a field name differed; an exclusion ignored at pay time; a correction
that paid twice. Verifiers earned their cost every single time.

Money changes get **mutation-tested** — break the fix in a scratch copy and
confirm the tests fail. A money fix without a test is not done.

Gates before every commit:
```bash
node --test tests/*.test.mjs && bash scripts/ci-invariants.sh && node scripts/check-ui-wiring.js
```
The lone CI failure (`css/styles-orig-verify.css`) is another session's untracked
scratch file, not yours.
