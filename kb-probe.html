Keyboard Probe

Diagnostic only — reads nothing, sends nothing, saves nothing. Answers the six questions that decide how the mobile window fix is built.

How to run this properly Open in Safari → Share → Add to Home Screen → launch it from the home screen icon. It must run standalone (no Safari toolbars) to measure what the real app experiences. The banner below tells you if you got it right.
